# Skippy blog

Follow Skippy releases, new inference capabilities, performance work, and
important changes for operators and contributors.

Release posts describe what changed, why it matters, how to adopt it, and any
compatibility or operational considerations. Engineering updates cover work
that is useful before it becomes part of a tagged release.
