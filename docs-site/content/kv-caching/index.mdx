# Prompt and KV caching

Skippy can restore model state for an exact or shared token prefix and avoid
recomputing all repeated prefill work. This improves time to first token for
stable system prompts, tool schemas, long documents, and multi-turn chats.

Applications continue to send the complete prompt or conversation. Skippy does
not perform fuzzy or semantic prompt matching. Reuse ends at the first token
that differs.

## Default policy

`prefix_cache = "auto"` follows the admitted model-family policy. Automatic
payload selection uses the loaded graph and native memory exporters so hybrid
or recurrent models retain all required state. If no complete representation
is available, prefix reuse is disabled while inference remains available.

```toml
[cache]
prefix_cache = "auto"
prefix_cache_budget = "auto"
prefix_cache_ram = "off"
kv_cache_disk = "off"
```

## Control prompt reuse

```toml
[cache]
prefix_cache = "on"       # auto, on, off, or record
prefix_cache_budget = "8GiB"
prefix_cache_max_entries = 256
prefix_cache_min_tokens = 512
prefix_cache_stride_tokens = 128
prefix_cache_record_limit = 4
```

Use `record` to populate state without serving hits. `off` disables lookup and
recording. Exact-state snapshots are indivisible, so one snapshot may exceed a
configured soft retention target.

## Choose live KV precision

```toml
[kv]
kv_cache_type_k = "q8_0"
kv_cache_type_v = "q8_0"
kv_cache_offload = true
flash_attention = "auto"
```

Supported explicit live K/V values are `f16`, `q8_0`, and `q4_0`. Quantized V
requires compatible Flash Attention and model geometry. An incompatible
explicit choice fails rather than silently changing precision.

## Observe cache behavior

OpenAI responses report reused tokens as
`usage.prompt_tokens_details.cached_tokens`. Skippy telemetry also reports hit
status, matched prefix tokens, suffix prefill tokens, and restore source.

For cache namespaces in OpenAI-compatible and Anthropic-compatible requests,
see [Deterministic caching](/getting-started/first-request/#deterministic-caching).
